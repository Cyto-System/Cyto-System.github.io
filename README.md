# Cyto Model Family

Official website for **Cyto System**, jointly developed by **Beijing Zhongguancun Academy (北京中关村学院)** and **BGI Research (华大研究院)**.

- Live site: https://cyto-system.github.io
- GitHub organization: https://github.com/Cyto-System

## Local Development

```bash
bun install
bun run dev
```

## Production Build

```bash
bun run build
```
